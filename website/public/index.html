Current, hourly, daily

Open-Meteo + NWS. 48-hour hourly strip and 5-day forecast with real Meteocons icons.

🎙️

AI weather podcast

Gemma 4 runs on-device via LiteRT-LM. Natural report, read aloud with a neural voice you choose.

🛰️

Animated radar

RainViewer + NWS tiles on an OSM base map (osmdroid) with Coil-backed overlay and playback controls.

🌐

Translate offline

ML Kit — 58 languages, models download once then work fully offline. No server round-trip.

🔔

Alerts & briefing

Severe-weather alerts and daily briefing via WorkManager + FCM. No account required.

Privacy first

Report never leaves your device. Only forecast + radar fetches hit the network. See Privacy Policy.
